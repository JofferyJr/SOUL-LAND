# SOUL-LAND

Browser-based fan-game prototype focused on Martial Soul inheritance, awakening, cultivation, Soul Rings, and comprehension.

## Current systems

- Martial Soul is inherited from the parents; the player does not choose it directly.
- Tool Spirits, Beast Spirits, and Body Spirits.
- Martial Soul Awakening at age 6.
- Parent Martial Soul quality influences inheritance.
- Rare Twin Martial Souls.
- Spirit Mutation.
- Innate Soul Power.
- Soul Master rank progression.
- Soul Rings.
- Comprehension progression.
- Martial Soul Approval / True Essence.
- Element's Heart eligibility.
- One with the Heavens.
- Early Laws of Heaven and Earth progression.

## Run

This is a static project. Open `index.html` directly, or deploy the repository with GitHub Pages.

## GitHub Pages

After merging this PR:

1. Open **Settings → Pages**.
2. Select **Deploy from a branch**.
3. Choose `main` and `/ (root)`.
4. Save.
